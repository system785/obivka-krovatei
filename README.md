# Обивка кроватей — сайт мастерской Монахова

Одностраничный сайт мастерской по перетяжке и обивке кроватей в Санкт-Петербурге и Ленинградской области. Работает как обычный статический сайт на GitHub Pages: без сервера, базы данных и сборки.

**Адрес сайта:** https://system785.github.io/obivka-krovatei/

## Что уже есть

- Главная страница с услугами, ценами, работами, отзывами, FAQ и формой заявки.
- Три SEO-статьи и страница-хаб со списком материалов.
- Цены указаны вместе с тканью: материал уже входит в стоимость перетяжки и обивки изголовья.
- Политика в отношении обработки персональных данных.
- Адаптивная вёрстка для смартфонов и десктопов.
- Анимации при прокрутке, счётчики, параллакс, плавные переходы.
- Мобильное меню, модальные окна, лайтбокс для фотографий.
- Формы с проверкой полей и передачей заявки в почтовую программу.
- `robots.txt`, `sitemap.xml`, микроразметка Schema.org, Open Graph.

## Как посмотреть локально

Можно просто открыть `index.html` в браузере. Для проверки всех ссылок и относительных путей удобнее запустить статический сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`.

## Как работает форма

Форма не отправляет данные на сервер. После проверки полей скрипт формирует письмо с именем, телефоном, выбранной услугой и комментарием и открывает почтовую программу с заполненным сообщением на `sey3@yandex.ru`. Если почтовая программа не открылась, на экране остаются адрес почты и телефон для прямой связи.

Сайт использует технические cookie и показывает уведомление при первом посещении. Согласие хранится в cookie браузера; подробности — в разделе 12 политики конфиденциальности.

Если в будущем понадобится сохранять заявки в CRM или на почту, нужно добавить обработчик на стороне сервера и заменить отправку в `assets/js/main.js`.

## Публикация на GitHub Pages

Репозиторий: https://github.com/system785/obivka-krovatei

1. Загрузите файлы в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.
5. Сохраните настройки и дождитесь публикации.

После публикации проверьте:

- https://system785.github.io/obivka-krovatei/
- https://system785.github.io/obivka-krovatei/robots.txt
- https://system785.github.io/obivka-krovatei/sitemap.xml

## SEO после публикации

1. Добавьте сайт в Яндекс Вебмастер и Google Search Console.
2. Отправьте `sitemap.xml` на проверку.
3. Проверьте, что главная и статьи открываются без ошибок.
4. При изменении цен или статей обновляйте `lastmod` в `sitemap.xml`.
